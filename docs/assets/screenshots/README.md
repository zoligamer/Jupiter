# 📱 Jupiter App Screenshots Showcase Folder

This folder hosts the screenshots displayed on the Jupiter website showcase section.

## 🖼️ File Naming Convention

Simply upload or replace your phone screenshots with the following exact filenames:

| Filename | Showcase Feature |
| :--- | :--- |
| `01-timetable.png` | **Instant Timetable & TO Office Hours** |
| `02-grades.png` | **Ghost Grades & Scholarship Index Simulator** |
| `03-petitions.png` | **Petitions, In-Progress Drafts & A4 Preview** |
| `04-finances.png` | **Finances & Scholarship Distinction** |
| `05-themes.png` | **Jovian Themes & Jiggly Spring Navigation** |

## 📐 Recommended Image Specifications
- **Format**: `.png` (recommended) or `.jpg` / `.webp`
- **Aspect Ratio**: Standard modern smartphone ratio (9:19.5 or 9:20), e.g. **1080 × 2400 px** or **1170 × 2532 px**
- **Quality**: Lossless PNG or high-quality JPG

## 🔄 Automatic Fallback Behavior
The website automatically detects if a `.png` file is present in this directory. If a file is not yet uploaded, it seamlessly falls back to the pixel-perfect vector `.svg` mockup already bundled in this directory (`01-timetable.svg`, `02-grades.svg`, etc.), ensuring the webpage always looks 100% complete and polished.
